## 2. 否定从句剥离规则（R-002）

**目标**：让「不用于 / 不适用 / 不涉及」后的词不再作为正向匹配信号，同时保留描述正文与输出。

**标记**（不区分大小写）：

```
不用于  不适用于  不涉及  Not for  not for
```

**切分**：

- 从标记出现的位置开始，删除到下一个终止符：`。`、`；`、`;`、换行，或字符串结尾。
- 不在 `，` / `,` 处截断，避免把「不用于：A、B、C」只删掉 A。
- 只影响送入 `tokenize` 的文本；`description` 原文仍用于 INDEX 与输出。
- 示例：
  - `……English triggers: …。不用于：直接扮演名人闲聊、书摘/读后感。` → 分词时删除「不用于：…」整段。
  - `……不适用于：体验目标与节奏（game-design-experience）、数值平衡（game-design-mechanics）。` → 分词时删除整段。

**边界**：

- 如果标记后没有终止符，删除到文本结尾。
- 如果同一段有多个标记，逐个处理。
- 不尝试理解语义，只做显式标记切分；不做同义词扩展。
- **已知限制（T-002 G3 P2）**：若 description 用 `；` 枚举多个否定项（如 `ai-comment-protection`），当前规则只删到第一个 `；`，后续项仍进入 tokens。候选 CR-006 处理，不在 T-002 范围。

## 3. roots 缓存比较（R-003）

- 读取缓存后，先把 `index["roots"]` 与本次请求的 roots 都转为 `Path.resolve()` 的绝对路径。
- 去重、排序后比较集合；集合不同 → `stale()` 返回 True，触发重建。
- 集合相同、顺序不同 → 视为相同，继续按 mtime 判断。
- 旧缓存里的 roots 可能是相对路径；两边都做同样的规范化，避免误判。
- 缓存 JSON 字段不变，只改判断逻辑。

## 4. 兼容与回滚

- CLI 参数、索引 JSON 字段不变。
- 旧缓存可读；roots 不一致时自动重建。
- 部署注意（T-002 G3 P1）：脚本升级后需执行一次 `capability_index.py build` 重建缓存；脚本版本感知由候选 CR-005 处理，不在 T-003 范围。
- 回滚：单文件 `git revert` / `git checkout -- skills/leverage-protocol/scripts/capability_index.py`。
- 不涉及数据迁移与外部服务。

## 6. CR-002 脚本可靠性设计

### 6.1 回填锚点

- 优先：`<!-- report-meta ... -->` 结束后的第一个空行。
- 回退：首个 `## ` 标题后。
- 两者都没有：stderr 输出 `[warn] 未找到日志插入点`，跳过回填，但 WORKLOG 仍写一次。
- 已存在 `- 工作日志：` 行时替换，不重复插入。

### 6.2 幂等键

- 同一次交付 = 同一报告路径 + role + gate + cr + task + action。
- `worklog.sh` 写入前检查 WORKLOG 是否已有同一报告链接 + role + gate + cr/task + action 的行；有则跳过。
- 不同报告路径不互相去重；不同 action 不互相去重。
- 不改变 WORKLOG 表结构；用现有列判断。

### 6.3 `--time` 格式

- 提取数字后统一格式化为 `YYYYMMDD-HHMMSS`；长度不足时补齐或拒绝。
- 默认路径保持 `LOG-YYYYMMDD-HHMMSS`。
- 同一秒的 `-2` 后缀逻辑保留。

### 6.4 usage 提取

- 用显式标记或 `awk` 截取开头连续注释块；禁止固定行号。
- 所有脚本统一一种方式。

### 6.5 无 python3 的相对路径

- 优先 `python3`；否则 `realpath --relative-to="$(dirname "$worklog")" "$report_abs"`。
- 两者都不可用：exit 2，stderr 明确，不写绝对路径。

### 6.6 selftest

- `scripts/selftest.sh` 在 mktemp 沙箱中复制脚本与最小夹具。
- 故障注入只改临时副本，绝不改仓库文件。
- 每个用例打印 PASS/FAIL，失败 exit 1；结束时清理。
- CI 在 `validate.sh` 之后执行。
