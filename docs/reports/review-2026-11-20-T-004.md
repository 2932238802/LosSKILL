## 缺陷清单

### [P1] WORKLOG 写入失败被静默吞掉，退出码 1 且无任何输出

- 位置：`scripts/finish-report.sh:290-298`（关键在 291-292 的 stderr 重定向与命令替换）
- 问题：新代码把 `worklog.sh` 的 stderr 重定向到临时文件，`log_id="$(...)"` 在 `set -e` 下失败即退出，`cat "$errfile"` 永远不会执行；失败原因被吞，临时文件也未清理。
- 触发条件：WORKLOG 写入失败，例如父目录不可创建/不可写、`--worklog` 指向目录、磁盘满、`mv` 失败。实测 `--worklog /proc/definitely-not/w.md` 与 `--worklog <一个目录>`。
- 影响：用户只得到 exit 1，无任何诊断信息；与 R-004 NFR「失败必须可见」直接冲突；修复前同一命令会输出 `mkdir: No such file or directory`，这是本任务引入的可观测性回归。
- 证据：
  - 修复后：`./scripts/finish-report.sh --report docs/reports/errpath.md --worklog /proc/definitely-not/w.md --no-auth` → `exit=1`，输出为空。
  - 修复前（HEAD 版本）：同命令 → `exit=1`，输出 `mkdir: No such file or directory`。
- 建议：显式处理失败：`if ! log_id="$("$worklog_script" "${args[@]}" 2>"$errfile")"; then rc=$?; cat "$errfile" >&2; rm -f "$errfile"; exit "$rc"; fi`；成功/跳过路径再决定是否透传 WARN。
- 置信度：高

### [P1] 去重键缺少 role/gate/cr/task，可误跳过不同交付

- 位置：`scripts/worklog.sh:123-131`（匹配串在 125 行）；与 133 行行模板对比
- 问题：实现只按「报告链接 + action」匹配，未比较 role/gate/cr/task。D-007 结论为「报告路径 + role + gate + cr + task + action」；设计 §6.2 第一条同样列出这些字段（第二条把实现检查写成 link+action，文档内部口径冲突）。
- 触发条件：同一报告链接、同一 action，但 role/gate/cr/task 不同。直接调用 `worklog.sh`（文档支持的手工补录路径）即可触发；`finish-report.sh` 使用 `--role/--gate/--cr/--task` 覆盖时也可触发。
- 影响：第二次调用被静默 `[skip]`，不同门禁/任务的日志行丢失，G4 审计的证据链出现缺口。
- 证据：沙箱连续两次 `worklog.sh --report reports/probe2.md --action 同链接动作`，第一次 role=dev/G2/CR-910/T-910，第二次 role=meta/G4/CR-911/T-911；第二次输出 `[skip] WORKLOG LOG-...（幂等键已存在）`，`grep -c '同链接动作' WORKLOG` = 1（期望 2）。
- 建议：匹配时同时校验 role、gate、CR/T 单元格；或由 Doc 明确裁决采用最小键并同步修改 D-007/§6.2，说明为何省略 role/gate/cr/task 是安全的。当前按 D-007 判定为不满足。
- 置信度：高

### [P2] `--force` 的文档承诺与实现不一致

- 证据：沙箱对已记录报告执行 `--force`，`T-099` 行数保持 1；help 输出第 36 行原文。
- 建议：更新 help/设计文案并在 T-005 落地；或将 force 显式传入 `worklog.sh` 作为受控旁路。判定为非阻塞，但需记录取舍。

### [P3] 幂等命中时 `[skip]` 信息重复输出

- 位置：`scripts/finish-report.sh:292`（透传 errfile）与 294（再次 echo）

- 影响：日志噪音，不影响行为。
- 建议：跳过时不重复 echo，或不让 worklog 在 stderr 重复。
- 置信度：高

### [P3] `--dry-run` 不反映幂等结果

- 触发条件：回填曾失败、再次 dry-run。
- 影响：预演结果误导。
- 建议：dry-run 也计算去重结果并标注 skip。
- 置信度：中（需先定义 dry-run 的期望语义）

### [P3] 报告路径含 `|` 时去重假阴性

- 置信度：高
