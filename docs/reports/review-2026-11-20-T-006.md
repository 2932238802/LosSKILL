### [P3] 受限 PATH 夹具 `make_bin` 白名单缺 `head`

- 位置：`scripts/selftest.sh:220`
- 问题：白名单为 `bash dirname basename awk grep sed date mktemp cat mv rm tr mkdir`，但 `scripts/worklog.sh:146` 与 `scripts/finish-report.sh:289` 均调用 `head -1`；在用例 9 的受限 PATH 下实际触发 `head: command not found`，被 `|| true` 吞掉。
- 触发条件：运行用例 9（`PATH="$bin_rp"` 且报告走 worklog 路径）。
- 影响：受限 PATH 夹具不完全等价「无 python3 的常规环境」；当前断言（rc、行数、相对链接）不受影响，故不构成假绿/假红，但会掩盖未来对 `head` 的依赖。
- 证据：去掉 `head` 的复刻夹具运行 `finish-report`，stderr 出现 `line 289: head: command not found`、`worklog.sh line 146: head: command not found`，rc 仍 0、1 行、相对链接。
- 建议：`make_bin` 增加 `head`（并顺带核对 `cut/wc` 等，若未来脚本引入）。
- 置信度：高

### [P3] 头部注释声称「9 个脚本含头部插行」，实际只对 `finish-report` 插行

- 证据：用例 12 的 `head_fr` 仅由 `finish-report.sh` 生成。

- 置信度：高

### [P3] SKIP 不失败：缺少 python3 / realpath 时覆盖率静默下降

- 位置：`scripts/selftest.sh:63, 248, 325`
- 问题：用例 9、13 在缺少 `realpath` / `python3` 时打印 SKIP，汇总仍 exit 0；AC-008-1 因此可在覆盖率不完整时显示绿色。
- 触发条件：非 CI 主机缺少 `realpath`（旧 macOS）或 `python3`。
- 影响：本地/其他环境可能误以为 AC-008-4 全覆盖；CI `ubuntu-latest` 两者具备，当前不受影响。
- 证据：`skip()` 只打印不计数；退出码仅由 `fail_n` 决定。
- 建议：CI 环境（如 `CI=true` 或 `GITHUB_ACTIONS=true`）下将意外 SKIP 视为 FAIL，或将 skip 数纳入汇总并在 CI 断言为 0。
- 置信度：中（对 CI 当前无影响）
