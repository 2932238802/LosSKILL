BRANCH 01 / ROLES

角色与边界

四个角色各自独立，交接靠文档与报告，不靠共享对话。

    授权阶梯

    你只在 G1 批准一次信封。越往下越不可逆，签字的人越少。

    A0

    只读与验证

    读代码、跑测试、lint、build、写临时文件。Agent 自主。

    A1

    低风险写入

    改代码、写文档、feature 分支 commit。Review 批准并记账。

    A2

    共享状态

    push、PR、合并 main、依赖与构建配置。Steward；低风险可委托 Review。

    A3

    不可逆

    生产部署、删库、force push、密钥与权限。只由用户确认。

    Review 不能批准自己的 G3 结论；Agent 不能替你点 Claude Code 的权限弹窗；A3 永不委托。

   ├─ overview.md

# 新增：
./scripts/new-skill.sh my-skill \
  --desc "当用户……时使用，产出……" \
  --not-for "相邻但不应触发的场景"

# 校验：
./scripts/validate.sh

# 安装 / 更新：
./scripts/sync-skills.sh --link --force

    description 必须写清「什么时候用、产出什么、不用于什么」；正文只留「何时读哪个文件」。
