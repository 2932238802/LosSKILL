# 拜访后四层复盘

## R — 原文

> 「导致复盘低效的第一个重要因素，就是缺乏统一的销售方法论。」
> —— 原则 47，L5319

> 「胜要胜得清清楚楚，败要败得明明白白。」
> —— 原则 47，L5310

## I — 我的理解

复盘不是"回忆一下感受"，而是用同一套标尺把一次拜访拆开看。作者给的是四层：

1. **整体**：对照访前规划——目标达成了吗？销售阶段与客户采购阶段匹配吗？有没有"清晰的下一步"共识？有没有掉进买家系统（被客户牵着走）？
2. **模块**：按方法论逐条检查——痛的三要素、预算、决策方式、方案时机，各在哪一步断了。
3. **情景再现**：挑出最不顺的一个环节，用反问/重说的方式再做一遍；销售不会做，经理示范。
4. **回到底层**：看态度、信念、自我价值感如何影响了这一场的行为与技巧。

四层的前提是"有统一方法"，否则每个人凭感觉总结，赢不知为何赢、输不知为何输。

## A1 — 书中案例

**案例一（reported_case，L5271–5292）**：经理与销售 Leo 的对话——Leo 凭"客户很感兴趣"判断有戏，经理只凭"不对的感觉"反驳，双方都没有标准，讨论变成拉锯。

**案例二（reported_case，L5303–5329）**：以赢单/丢单论英雄的复盘（反例），结论停在"客户不诚心"。

## A2 — 何时会被用到

- 刚结束一次重要拜访，想搞清哪里出了问题
- 团队复盘会总是变成"讲过程+喊口号"
- 想知道下一次同一个客户该怎么开
- 用户会说：「帮我复盘这次拜访」「这次为什么没推进」「客户走了之后我该总结什么」「review this sales call」
- **与相邻能力的区分**：本能力处理"已发生的拜访怎么拆"；"下一个机会要不要跟"属于机会甄别；"客户说考虑考虑怎么办"属于含糊即拒绝。

## E — 执行步骤

**输入契约（缺项先问）**
- 本次拜访的事实记录（时间、参与人、关键对话，必需）
- 访前定的目标与议程（可缺，缺则只能做后两层）
- 客户所处采购阶段（可选）
- 当前使用的方法论（可选，缺则用本卡四层）

**步骤**
1. **第一层：整体**（对照访前规划）
   - 目标达成度：达成 / 部分 / 未达成，各附一句证据。
   - 阶段匹配：销售做了什么、客户在哪一阶段，是否错位。
   - 下一步：是否有具体对象、动作、时间；没有就是"无共识"。
   - 控制权：是否出现"客户主导节奏"的信号（被要求免费方案、被反复改期、被转交低层级）。
2. **第二层：模块**（逐项打勾）
   - 痛：是否确认？表现/原因/影响齐吗？
   - 预算：是否谈过？区间与审批人明确吗？
   - 决策：名单、流程、拍板人清楚吗？
   - 方案：时机是否合适？客户是否已有倾向？
3. **第三层：情景再现**
   - 选出最差的一个 30 秒片段，原话重放。
   - 用"如果重来一次"改写 2–3 句（反问、挑破、退回诊断）。
   - 若销售做不出，由经理示范一遍。
4. **第四层：底层**
   - 哪一刻因为怕丢单而让步/不敢问？
   - 哪一句话暴露了限制性信念（客户只认价格 / 我不该提要求 / 大老板不会见我）？
5. **产出动作**：不超过 3 条可执行改进，明确到"下次见这个客户时第一句话说什么"。

**判停与分支**
- 客户信息不足（只记得"聊得不错"） → 只做第一层与第四层，并在下次拜访补记录。
- 复盘发现"没有访前规划" → 先把 `upfront-contract` 补上，再做本复盘。
- 出现"以赢单/丢单论英雄" → 停止结论，回到四层。

**输出契约**
四段式记录：`整体（4 项）| 模块（4 项打勾）| 情景再现（原话+改写）| 底层（1–2 条信念）`；结尾 `下阶段 3 条动作（含第一句话）`。

## B — 边界

- **不要用在**：纯信息同步会议；客户尚未接触过的冷启动阶段（无行为可复盘）。
- **作者警告的失败模式**：以赢单/丢单论英雄（ce25）；"我总结过了"式自我安慰（L5328–5329）；"从经验中来，到经验中去"的传帮带（L5317–5318）。
- **作者盲点**：复盘标准取自桑德拉自己的方法论（L5347–5348），用它的尺子量别的打法会系统性判负；对没有教练的一线销售，第三层的"经理示范"不可得。
- **相邻易混**：与"机会甄别"互补——复盘常以"是否该早点结案"收尾；与"事先约定"构成闭环：没有约定就没有第一层的对照基准。
