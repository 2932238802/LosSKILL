# 能力：设计伦理与责任评估

## R — 原文

> "要创造成功且有意义的改变，你必须非常明确地表明改变的内容，以及你的游戏具体将如何促成这种改变。"（第 32 章，PDF p573–576）

> "我总结了5个层面的评估项，严格程度越来越高。"（第 32 章，PDF p574–575）

> "如果你不愿意为你制作的游戏承担个人责任，那你就不应该制作它们。"（第 33 章，PDF p583–585）

## I — 自述

游戏会改变玩家。这个改变可以是教育、健康、社会连接，也可以是成瘾、焦虑、仇恨。设计师不能把责任外包给公司、律师或"玩家自己选择的"。

评估分两层：

**塑造性游戏（以改变为目的）**要回答七个问题：改变什么（具体到"通过什么机制、让谁、发生什么变化"）、找哪两类专家（内容专家 + 教学专家）、如何服务教师而非取代教师、如何避免做得太多、证据到哪一级、在什么场所发生、市场能否支撑。

**证据分五级**：1 感觉大概有用；2 故事趣闻；3 领域专家认同；4 非正式前后测；5 科学测试与评估。1–3 级不能作为有效性证据；5 级多数小团队做不起，但至少要诚实标注自己处在哪一级。

**责任判断**：企业只对法律与利润负责，没有道德责任；"律师说可以""发行商会把关"不是免责；设计师通常默默无闻，没人会要求你负责，所以必须自我问责；对无法承担个人责任的项目，选择不做。

## A1 — 应用示例

书中案例：作者的严肃游戏项目（第 32 章）——先写清"玩家在什么场景下、通过什么机制、发生什么具体变化"，再找内容专家与教学专家；评估只做到"专家认同 + 非正式前后测"，并在对外材料中如实标注证据等级。作者未给对照实验数据。

书中案例：作者拒绝某类项目（第 33 章）——当无法承担个人责任时选择不接；书中未给具体项目细节，属于规范性主张。

## A2 — 何时触发

- 用户说"这个设计会不会上瘾""付费点有没有伦理问题""教育游戏怎么做""游戏能改变人吗""要不要接这个项目"。
- 用户在设计与未成年人、赌博机制、社交压力、成瘾循环相关的系统。
- 用户要为一款"严肃游戏"写目标、评估方案或对外声明。
- 英文信号：ethics、serious game、addiction、dark patterns、social impact、responsibility。

与相邻能力的区别：`game-design-player` 解释动机机制；本能力做**价值判断与证据分级**；`game-design-business` 管商业可行性，但商业可行不构成伦理正当。

## E — 执行

**输入契约**：游戏的核心循环与付费设计；目标人群（是否含未成年人）；预期改变或风险；可用评估预算；团队/雇主约束。

**步骤**

1. **列影响清单**：写出游戏可能带来的正负影响（时间占用、情绪、社交、消费、认知），标出受影响人群与证据来源。完成标准：至少 3 条负影响，不能只写好处。
2. **定位证据等级**：对每个"预期改变"标注 1–5 级；1–3 级不得对外宣称"有效"。完成标准：每条声明都有等级与依据。
3. **审查机制**：检查是否存在强迫打卡、损失厌恶滥用、无限随机奖励、社交攀比、未成年人付费诱导；逐条写"保留/修改/删除 + 理由"。
4. **写改变定义**（塑造性项目）：用"通过什么机制、让谁、发生什么具体变化"的句式；找内容专家与教学专家各一名；决定服务教师还是替代教师。
5. **选评估方案**：按预算选前后测/专家评审/对照实验；写明样本、周期、判定标准；达不到就降级声明。
6. **做个人责任判断**：写下"我是否愿意为这个设计署名并承担后果"；若否，列出必须修改或拒绝的点。

**输出契约**：影响清单（正/负 | 人群 | 证据）；证据等级表；机制审查表（保留/修改/删除）；改变定义（塑造性项目）；评估方案；责任判断与拒绝清单。

**判停**：负影响无法缓解且目标人群含未成年人 → 停止或重设计；证据等级 <4 却要对外宣称有效 → 停止宣称；个人不愿署名 → 拒绝或退出。

## B — 边界

- 这是伦理框架，不是法律意见；合规问题需律师。
- 书中伦理讨论多为规范性主张与轶事，缺阈值、量表与对照实验；不能把作者判断当实证结论。
- 五级评估中第 5 级成本高，小团队通常做不到；诚实标注等级比伪造证据重要。
- 不适用于纯粹的艺术表达审查；本能力只评估对玩家的可预见影响。
- 与雇主/合同冲突时，原书未给组织策略；本能力只提供个人判断框架。
