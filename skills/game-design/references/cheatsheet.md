# 决策规则速查 — 游戏设计艺术（第2版）

| 能力 | 一句话规则 |
|---|---|
| 游戏体验目标设计 | 先写一句可检验的体验陈述，再定位场景、找表达手段、画兴趣曲线；找不到元素的特征只是愿望。 |
| 四元素与统一主题分析 | 机制、故事、美学、技术四栏等权拆解，再用一句话主题过滤所有元素。 |
| 创意、原型与迭代计划 | 问题陈述→大量创意→按风险排序→最小原型→测试→更具体的问题；每轮只消除最大风险。 |
| 八项测试设计评审 | 艺术冲动、受众、体验、革新、商业、工程、社交、试玩八项逐条过；任何修改后全量重跑。 |
| 机制设计与平衡 | 用七项机制盘点建骨架，用期望值与十二类平衡审计调体验，删掉无意义选择。 |
| 故事、世界与角色设计 | 选珍珠串/故事机/英雄之旅结构，先列角色功能再配对，用关系图与地位翻转写场景，用间接控制引导玩家。 |
| 试玩测试设计与执行 | 用"为什么/谁/在哪/发生什么/怎么发生"定义测试，看玩家的脸，问具体问题，不为设计辩护。 |
| 玩家动机与心流诊断 | 查心流四条件，再查马斯洛/SDT 需求覆盖，最后把动机放进"内外×想做/得做"矩阵。 |
| 游戏界面与反馈设计 | 画六条数据流，给信息分级并分配通道，把输入反馈压到 0.1 秒，保证外观与行为一致。 |
| 团队协作与设计文档 | 先定参与与拍板结构，再按"备忘/沟通"选文档，用一页设计对齐全局。 |
| 商业模式与推销 | 先画钱流图与 LTV/CAC，再判断七类壁垒，最后用可复演的推销结构要资源。 |
| 多人游戏与社群设计 | 先回答五种社交动机，再定一个社群矛盾，用信息不对称迫使玩家互相依靠。 |
| 设计伦理与责任评估 | 列正负影响，标注证据等级（1–5），审查强迫与成瘾机制，最后做个人署名判断。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
