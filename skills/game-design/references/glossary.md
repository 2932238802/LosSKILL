# 术语表（作者用法）

> 以原书定义为准；括号内为常见误解或差异。OCR 版本可能有个别错字，引用原文请对照纸书。

| 术语 | 作者的定义/用法 | 与常识用法的差异 |
|---|---|---|
| 体验（experience） | 玩家在游戏过程中产生的感受与记忆；游戏本身不等于体验 | 不是游戏内容，也不是画面表现 |
| 本质体验（essential experience） | 一个体验中定义其身份的关键特征集合 | 不是完整复制真实体验 |
| 场景（scene） | 玩家使用技术的地点、姿态、社交关系与情境 | 不等于平台或市场细分 |
| 内生价值（endogenous value） | 只在游戏内部成立的价值（分数、资源） | 不等于现实货币价值 |
| 魔法圈（magic circle） | 游戏划出的、与现实规则分离的边界 | 不是物理空间 |
| 透镜（lens） | 一组从特定角度审视设计的问题 | 不是设计模式，也不是必过清单 |
| 元素四分法 | 机制、故事、美学、技术四种基本元素，地位平等 | 不是"玩法最重要"的层级 |
| 机制（mechanics） | 游戏中的过程与规则；玩家怎样达成目标、尝试时会发生什么 | 不只是战斗/数值 |
| 故事（story） | 游戏中事件展开的顺序，可线性、分支或随机 | 不等于世界观设定或台词 |
| 美学（aesthetics） | 游戏的外观、声音、气味、味道和感觉 | 不只是美术风格 |
| 技术（technology） | 让游戏得以实现的材质与交互媒介 | 不只是"高科技" |
| 主题（theme） | 一句话说明游戏"是关于什么的"，用于统一所有元素 | 不是装饰或隐藏象征 |
| 统一主题（unifying theme） | 让机制、故事、美学、技术朝同一方向工作的主题 | 不要求每个细节都象征化 |
| 共鸣主题（resonant theme） | 能触动玩家已有情感或真相的主题 | 不是所有游戏都需要 |
| 全息设计（holistic design） | 同时观察玩家体验与产生体验的元素 | 不是单看体验或单看结构 |
| 八项测试（eight filters） | 艺术冲动、受众、体验设计、革新、商业、工程、社交/社区、试玩测试 | 不是八个开发阶段 |
| 迭代规则 | 测试和改进的次数越多，游戏越出色 | 不等于"多改几版"；方向错误时无效 |
| 兴趣曲线（interest curve） | 体验强度随时间变化的曲线 | 不是难度曲线，也不等于节奏 |
| 心流（flow） | 挑战与能力匹配时的高度投入状态 | 不等于"好玩"或"上瘾" |
| 有意义的选择 | 会改变结局、且有代价的选择 | 无代价或结果相同的选择不算 |
| 平衡（balance） | 把元素调到能传达目标体验，而非数值平均 | 不是所有选项一样强 |
| 间接控制（indirect control） | 通过限制、目标、界面、视觉、角色、音乐影响玩家，而不直接下令 | 不是删除玩家自由 |
| 故事机（story machine） | 让玩家在游戏中自行生成故事片段的系统 | 不是预设剧情播放器 |
| 英雄之旅（hero's journey） | 启程—试炼—回归的叙事结构，用于诊断 | 不是必填公式 |
| 塑造性游戏（transformative game） | 以改变玩家认知/行为为目的的游戏 | 不等于"教育游戏"这一品类 |
| 证据五级 | 感觉有用、轶事、专家认同、非正式前后测、科学评估 | 前三级不能作为有效性证据 |
