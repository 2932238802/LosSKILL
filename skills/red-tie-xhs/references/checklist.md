# 发布前检查

## 内容底线

- [ ] 事实与观点表述客观正确 没有未经查证的断言
- [ ] 区分了事实 研究结论 个人推断
- [ ] 书籍类区分了作者原意 二手解读 自己的推论
- [ ] 人性类没有把相关性说成因果 没有过度概括
- [ ] 书籍类没有臆造原文 写明了前提和适用边界
- [ ] 版本差异 前提差异 实现差异已写明
- [ ] 每个信息模块都有干货 没有正确的废话
- [ ] 每张图至少 4 条可验证事实 步骤 数字 或边界
- [ ] 没有故事化铺垫 没有与主题无关的比喻
- [ ] 删除后不影响信息量的句子已经删除
- [ ] 最后一张能独立当速查表收藏
- [ ] 没有为了凑页数 凑字数灌水
- [ ] 标题 封面能由正文兑现 不存在标题党
- [ ] 没有绝对化词语 必看 封神 全网最全 史上最强
- [ ] 没有恐吓式表达 制造焦虑 或贬低群体
- [ ] 没有虚构经历 数据 或权威来源

## 内容准确性

- [ ] 主题语境明确
- [ ] 定义准确且包含必要边界
- [ ] 没有用比喻代替定义 确需类比时已标注边界
- [ ] 没有为了流量制造错误结论
- [ ] 涉及的代码和命令可以正常运行
- [ ] 复杂度 数值 案例引用和出处正确

## 图片

- [ ] 正好 6 张
- [ ] 每张 1080 × 1440
- [ ] 只使用黑白灰 没有彩色
- [ ] 全篇统一深色背景
- [ ] 每张只有一个大标题加若干条目
- [ ] 没有圆角卡片框 描边框或多层底色
- [ ] 没有页码 页脚 系列名 装饰线
- [ ] 模块之间留白充足 页面有呼吸感
- [ ] 图片内没有 emoji
- [ ] 图片内没有中文句号
- [ ] 中文行没有使用 Consolas
- [ ] 无豆腐块 乱码 错位
- [ ] 无文字重叠 溢出 裁切
- [ ] 封面标题一眼可读
- [ ] 插画或示意元素不越界
- [ ] 页脚有安全距离

## 标题

- [ ] 共 5 条
- [ ] 每条尽量 12 到 20 字
- [ ] 分别覆盖痛点 好奇 反差 收藏 搜索
- [ ] 至少包含一个核心搜索词
- [ ] 没有虚假承诺或绝对化词语
- [ ] 标题内容能在正文和图片中找到对应
- [ ] 没有 必看 封神 全网最全 看完秒懂 这类博眼球话术

## 正文

- [ ] 350 到 650 字为主
- [ ] 前 3 行命中身份 痛点 结果 悬念中的两个
- [ ] 先给结论再解释
- [ ] 每段 1 到 3 行
- [ ] 没有把每个短句都单独换行
- [ ] 使用 3 到 5 个 🔹 小节
- [ ] 有一个真正容易错的点
- [ ] 与图片互补而不是逐字重复
- [ ] 结尾有自然互动钩子
- [ ] 没有明显站外导流

## 标签

- [ ] 8 到 12 个
- [ ] 有领域大词
- [ ] 有精准概念词
- [ ] 有受众或使用场景词
- [ ] 没有堆无关热点词
