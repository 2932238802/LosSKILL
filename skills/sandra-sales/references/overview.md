# 桑德拉销售原则 — 全书概览（随包交付）

## 一句话

销售低效的根因不是技巧不足，而是用「卖家系统」逼单：客户早有「买家系统」反制；改用「协助客户购买 + 主动甄别机会」，把痛、预算、决策、方案、签约、复盘逐个前置，才能在保住尊严的同时稳定成单。

## 七层骨架

1. **判据**：客户四步反制（误导 → 套免费信息 → 不承诺 → 消失），传统四步销售必然激发它（原则 1–5）。
2. **心态**：能力 = 态度 + 行为 + 技巧；本体（我是谁）与角色（做什么）分开（原则 6–12）。
3. **入口**：客户开发是定义问题（ICP、分级、转介绍、创收时间），不是努力问题（原则 13–16）。
4. **设计**：拜访靠规划与「事先约定」，不靠即兴（原则 17、29）。
5. **推进**：少说、多问、示弱、装傻、第三方故事，用低威胁换真相；痛之前不讲 FAB（原则 18–28、30–36）。
6. **硬节点**：痛 → 甄别 → 预算 → 决策链 → 方案时机 → 签约防反悔，每个节点都是双方共同判断（原则 37–46）。
7. **闭环**：统一方法论复盘；满意度与终身价值经营客户（原则 47–49）。

## 关键判断规则（速查）

- 需求可以撒谎，痛必须描述出表现、原因、影响，并由客户亲口承认。
- 三柱（痛/预算/决策）缺一且无法补齐 → 调整或结案。
- 没有具体下一步的"考虑考虑" = No。
- 客户没有倾向之前，不做完整方案。
- 价格差距出现时：承认、问预期、要建议，不自我证明、不主动降价。
- 签字前主动给客户反悔的机会。
- 结果不可控，行为量可控：目标 → 缺口 → 新客户数 → 各环节量 → 日历。

## 边界（读这本书时必须知道的）

- 场景原型是关系型、线下的 B2B 大额采购；电子招标、集采、平台化比价、高频低客单覆盖不足。
- 默认销售有定价授权与可调度资源（专业书、讲座、打样、高层参与）；无授权的一线销售多数动作不可执行。
- 关键比例（80/20/95 反对意见、90% 方案过早、70% 时间客户说话、二八、1/5 维护成本、3 倍训练效果）均无出处，只可作方向，不可当阈值。
- 心态层（金三角、限制性信念、本体/角色、T-A）是自我诊断材料，不是可判定完成的任务。
- 书名与体系名中的"钟摆原理""傻子曲线""OK-Not OK""(4+1) 拜访结果""30 秒广告"在正文只有清单式引用，没有定义，不应据名称推演。

## 内部张力（保留，不裁决）

- 原则 39「认知不匹配尽早放弃」 vs 原则 40「持续创造价值」：同一客户的资源方向相反。
- 原则 22「不画海鸥」 vs 原则 23「拆引信」：形式相同、方向相反；区分判据是"是否由客户自己说出"。
- "购买原点是情绪" vs 制度性决策案例（评审委员会、价低者中标）。
