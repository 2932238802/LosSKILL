# 桑德拉销售原则 — 术语表（作者用法）

> 用法：所有能力卡共享此表。凡与常识用法不同处，以本表为准。

| 术语 | 作者的定义 | 与常识的差异 |
|---|---|---|
| 卖家系统 | 引起兴趣/了解需求 → 展示产品方案 → 试图成交 → 持续跟进，底层动机是"总是想快点成交"（L701–756） | 常识把它当中性流程；作者判定它有道德缺陷、被客户识破后必然失效 |
| 买家系统 | 客户四步反制：误导你 → 获取免费资讯 → 不做承诺 → 消失不见（L816–863） | 常识的"采购流程"是制度描述；作者写成对抗性战术 |
| 甄别（qualifying） | 用痛、预算、决策三模块判断机会真伪与匹配度，不匹配即主动退出（L986–998） | 常识"筛客户"是资格审核；作者强调双向匹配 + 主动放弃权 |
| 成功金三角（A/B/T） | 态度、行为、技巧三者相互关联、必须协同；技巧只占三分之一（L1149–1212） | 常识把销售能力等同技巧 |
| 痛 | 现状与预期的差距，含已出现的问题、对未来的恐惧、可获得的收益，带情绪（L4284–4306） | 常识"痛点"= 业务问题；作者要求可查证（表现/原因/影响） |
| 需求 | 客户口述的愿望，可以夸张、可以撒谎（L4305–4306） | 常识视为购买信号；作者视为需要被证伪的表层信息 |
| FAB | Feature / Advantage / Benefit；在痛被确认前使用即失效（L4177、L4221） | 常识当作推销标准框架；本书列为应停止的动作 |
| 事先约定（Up-Front Contract） | 会前就目的、参与人与时间、客户议题、销售议题、期待输出达成共识，并约定"什么算犯规"（L3497–3499） | 常识理解为"约时间" |
| 本体 / 角色（I/R） | 本体是"我是谁"（天生满分 10 分），角色是"做什么"（L1352–1360） | 常识的自我价值随业绩浮动 |
| 限制性信念 | 坚信不疑但妨碍行动的认知，需先于技巧被清除（L1270–1301）；书中为单句口径（partial） | 常识的"信念"偏激励词；作者当可证伪的错误前提 |
| 撒糖果 | 在客户承认痛之前抛出价值与专业度（L2385–2429） | 常识视为"主动服务" |
| 画海鸥 | 擅自替客户修改他的需求图像（L2810–2851） | 常识视为"帮客户想周全" |
| 拆引信 | 在客户爆发前，自己先说出产品短板并给补偿（L2872–2931） | 常识倾向于隐藏短板 |
| 以退为进（消极反向提问） | 明示"不买也可以"，用退让换取真相（L2571–2641） | 常识视为放弃成交；"消极反向提问"全书无独立定义 |
| 第三方故事 | 用他人经历承载自己的顾虑，使矛头不指向眼前客户（L3979–4020） | 常识"举例说服"是证明产品；此处是表达感受 |
| 创收时间 / 警戒线 | 直接产生收入的时间；学习、做方案、客户规划都算非创收（L2181–2211） | 常识把"加班时长"当勤奋 |
| 果敢 | 明确下一步、要求具体承诺、必要时放弃，且可表现温和（L5020–5042） | 常识"果敢"接近咄咄逼人 |
| 复盘 | 以统一方法论为标尺，做整体/模块/情景再现/金三角四层回顾（L5312–5364） | 常识"总结经验"凭感觉 |
| K.A.R.E | Keep / Attain / Recapture / Expand 四类，类内再分重要性（L4638–4652） | 常识客户分级按规模或成交额 |
| 终身价值 | 按客户全生命周期总贡献配置资源（L5506–5525）；只有口径无算法（partial） | 常识属营销预算概念 |
| 决策地图 | 多个决策人的喜恶、立场、动机、痛点分布（L5528–5533）；只有单句（partial） | 常识理解为组织架构图 |
| 钟摆原理 | **全书无定义**：9 处引用中 5 处是"关联知识点"清单，正文仅引述学员提问（L2633） | 不得据名称推演；见 needs-review |
| 傻子曲线 / 好奇曲线 | **全书无定义**：8 处全为清单引用 | 同上 |
| OK-Not OK | **全书无定义**：4 处全为清单引用 | 同上 |
| (4+1) 积极的拜访结果 | **全书无定义**：仅 2 处清单引用（L3148、L3788） | 同上 |
| 30 秒广告（法） | **全书无定义**：5 处仅名称 | 同上 |
| 痛的拼图 / 痛的漏斗 | **全书无定义**：仅名称 | 同上 |
