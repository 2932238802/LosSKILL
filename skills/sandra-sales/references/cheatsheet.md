# 决策规则速查 — 桑德拉销售原则（中国本土案例版）

| 能力 | 一句话规则 |
|---|---|
| 机会甄别与去留决断 | 三柱（痛/预算/决策）缺一且无法补齐，就调整或结案，而不是再努力试试。 |
| 痛诊断：把需求追问成痛 | 客户说不出影响，就还没有痛；没有痛，不进方案。 |
| 访前规划与事先约定 | 会前不谈规则，会后无权抱怨。 |
| 反对意见分诊与拆引信 | 先判反对意见是自造的、真实的还是烟幕，再决定动作。 |
| 谈钱：预算对话与价格差距 | 差距出现时只说差距、问预期、要建议，不自我证明也不主动降价。 |
| 拜访后四层复盘 | 用同一套标尺拆四层：整体、模块、情景再现、底层信念。 |
| 客户开发系统：ICP、分级、转介绍、创收时间与行为量 | 把不可控的目标换成可控的行为量，并把入口建成五个可设计的部件。 |
| 免费工作闸门 | 先问"做完之后您这边怎么走"，再决定做不做。 |
| 含糊即拒绝：允许客户说 No | 没有具体下一步的"考虑考虑"，按 No 处理并给客户说不的安全感。 |
| 低威胁对话术：示弱、装傻与第三方故事 | 降低威胁感，换取真实信息；技巧必须落回信息与承诺。 |
| 时机匹配：购买阶段、方案闸门与不逼单 | 客户没有倾向之前不做完整方案；不逼单，只确认障碍。 |
| 签约前反悔测试 | 签字前主动给客户反悔的机会，把疑虑在还能处理时处理掉。 |
| 客户经营：K.A.R.E、满意度与终身价值 | 按 K.A.R.E 分配资源，用七项评分把满意度变成数字，按终身价值经营。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
