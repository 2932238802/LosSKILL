# 桑德拉销售原则（中国本土案例版） — 来源路由入口（compact pack）

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 书摘、读后感、作者人设角色扮演
- 通用营销、品牌投放、电商运营
- 法定招标文件的逐条应答与合规审查
- 定价策略与折扣授权决策（本书只讲对话，不讲定价）

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 客户有反制脚本（误导、套免费信息、不承诺、消失），传统的"卖家系统"必然激发它；出发点是协助购买 + 主动甄别。
2. 需求是客户说的话，痛是客户身上可查证的事实；痛未确认前不展示价值。
3. 每个高致死率节点（预算、决策者、方案时机、签约疑虑）都尽量前置，越晚碰越贵。
4. 含糊即拒绝：没有具体下一步的"考虑考虑"按 No 处理。
5. 手段服务于真相：示弱、装傻、反问、第三方故事都是为了换取信息与承诺。
