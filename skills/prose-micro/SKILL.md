# 小切口散文

## 怎么用我

1. 先问素材：这件事里**最具体的一个动作**是什么（一张卡、一次满减、谁先看报告）。
2. 不写"她对我很好"，写她做了什么；不写"环境不好"，写一个价格或一次等待。
3. 按时间顺序平铺，不插评论、不总结、不升华。
4. 写完后按第 7 节自检，再交给用户。
5. 细节必须是真实的；虚构的要标明，别冒充经历。

## 核心三条

1. **小切口**：一篇只写一件事、一个物件、一个动作。切口越小，力量越大。
2. **平铺叙事**：像讲一件已经过去的事，按时间说。不解释动机，不点明意义。
3. **耐人寻味**：结尾停在一个动作或物件上，把判断留给读者。

## 选题：小动作 → 大环境 → 人性

不直接写时代，写**一个价格、一次等待、一个没说出口的数字**。

| 小动作 | 环境切片 | 人性切片 |
|---|---|---|
| 凑外卖满减，差三块 | 消费降级 | 都说自己吃饱了 |
| 投简历到对方公司 | 就业寒冬 | 瞒着，是自尊还是算计 |
| 房租涨了，谁先说搬 | 城市生存 | 谁承担决定 |
| 电话里报一个彩礼数 | 婚恋成本 | 讨价还价里的体面 |
| 体检报告谁先看 | 医疗焦虑 | 你更怕失去谁 |
| 被裁了照样出门 | 裁员潮 | 撒谎是为了护谁 |
| 通勤一小时说"当锻炼" | 城市尺度 | 自我安慰的本事 |

选材标准：这个动作**不解释也能被看见**，且能牵出一个更大的东西。

## 结构：平铺

- 时间顺序：那天 → 第二天 → 一个星期后。
- 每一段只放一个动作或一句对话。
- 不写心理分析，最多一句"她看见了，没说话"。
- 不写"后来我才明白"这类回望句。
- 结尾停在动作：把卡放进抽屉、把冰箱塞满、把钥匙挂上。

## 语言

- 短句为主；一句一个动作。
- 少形容词；用名词和动词承担情绪。
- 对话用白描，不加"她温柔地说"。
- 不排比、不金句、不点题。
- 不写"我不禁想起"。

## 两面性：同一种在乎的两个面目

金刚怒目、菩萨低眉不是两种性格，是同一出发点的两种形式：

- 怒目：把事说穿、拦住你做错的事、说重话。
- 低眉：留饭、留灯、替你把东西收好、不追问。

写法：让两者出现在**同一个动作序列**里（骂完、递筷子、夹菜、说先吃），不要分开论述。

判断边界：怒目若带羞辱就是打压，低眉若带交换就是讨好。分水岭是——事后对方是更能站住，还是更依赖你。

## 自检清单

- [ ] 切口是不是小到一个物件/一个动作
- [ ] 有没有一句在解释意义（有就删）
- [ ] 结尾是不是停在动作上，而不是总结
- [ ] 有没有直接写"环境不好""人性复杂"（有就换成细节）
- [ ] 形容词是不是可以再删一半
- [ ] 细节是真的吗；虚构有没有标注
- [ ] 读完有没有一个想问的问题（有，说明耐人寻味）

## 反例

- 「她是一个温柔又坚强的人」→ 改成她做了什么。
- 「这个时代对年轻人不友好」→ 改成一个具体价格。
- 「我终于明白了爱的意义」→ 删掉，停在动作上。
- 三段否定 + 清单 + 点题的金句结构 → 模板腔，重写。
